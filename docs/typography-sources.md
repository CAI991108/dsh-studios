# Typography revision
User asked to replace heavy default-looking Chinese titles with a mature product-film treatment.
Primary sources inspected:
- Xiaomi MiSans official font and about pages: https://hyperos.mi.com/font/zh/ and https://hyperos.mi.com/font/zh/about/
- Xiaomi official FAQ: https://hyperos.mi.com/font/zh/faq/
- Vercel Geist font and typography: https://vercel.com/font and https://vercel.com/geist/typography
- Apple official font system: https://developer.apple.com/fonts/
- Product-film creator case: Design PUTAO, HyperOS 生命感美学: https://www.behance.net/gallery/210500233/HyperOS-

Choice: MiSans variable for Chinese and accompanying Latin. Use a controlled semibold headline, medium caption, tighter two-line composition, and natural punctuation alignment. Actual product UI textures retain their original typography. The film creator case supports composition reference; the exact font in that film is not independently identified. MiSans family attribution comes from Xiaomi's own typography documentation, not visual font guessing.

Source file: official MiSans.zip, bundled as part of this film project with attribution. MiSans is designed by Xiaomi with partners; font copyright remains with its rightsholders. See official agreement: https://hyperos.mi.com/font-download/MiSans字体知识产权许可协议.pdf
