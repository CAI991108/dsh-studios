## 产品简报
受众：B站/YouTube 的桌面美化、开源、AI工具、二次元兴趣用户。中文旁白，16:9 1920×1080，30fps，目标约两分钟（以实际旁白节奏微调）。
产品来源：CAI991108/omarchy-NTE，取样提交 8fd2d4dcad3f9666ca3fd9acf1afcde1aa3a7d30。
主张：一套能让人更愿意打开电脑的视觉配置。桌面约三成、DSH约六成、复现与收尾约一成；不做 Linux 安装教学，不介绍无关生态。
真实边界：皮肤不提高模型能力；滑轨选择的是模型提供的 reasoning effort 档位，档数随模型目录而定。轻量指小图、CSS、插件与可复现配置，不做整体内存/CPU性能承诺。

## 视觉与声音方向
比较三个方向：纯桌面音乐片（画面充分但梗不够）、高密度鬼畜（易遮挡真实界面）、认真口吻的科技整活（选定）。
本片主题：生产力，稍后再说。用明亮壁纸开眼，再转入深色像素星野。
产品 tokens：Catppuccin Mocha base #1e1e2e，mantle #181825，text #cdd6f4，subtext #a6adc8，blue #89b4fa，lavender #b4befe，mauve #cba6f7，pink #f5c2e7；壁纸红/天蓝仅在桌面段自然出现。
字体：小米官方 MiSans VF，标题520、字幕400，实际字体轴150–700；代码 Cascadia Code / Consolas。字幕60px、辅助≥32px。像素头像按原图 nearest-neighbor，不伪造别的吉祥物。
节奏：UI真实交互保持可读；段间单主动作；开场主体动作≥3秒；笑点留0.4–0.8秒空拍；字标落定≥1秒；不做全片震屏。
声音：中文男声冷静讲述；原创120BPM电子鼓底；UI拟音采用技能库真实键击/机械开关/电影转场。关键笑点降低配乐，非逐拍震画面。
编曲例外：采用本片原创程序编曲，保证出处可追溯；不使用库中来源无法逐曲反查的 BGM。不把每个词都做音效。

## 镜头语法与定案
参考 promo-energy-arc，延长产品观察段而非照搬30秒模板。采用 error-retype 的改口速度与光标三态、outro-group-photo-launch 的四方归位与12帧真过冲。源码按 Gallery 索引读取；其余 UI 动作直接来自产品运行时，镜头编排为本片自定义。
